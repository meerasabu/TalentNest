# TalentNest Frontend 🎨

This directory contains the React-based frontend for TalentNest, built with Vite for high performance and modern developer experience.

## 🚀 Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## 🛠️ Key Components

- **Dashboard/Index.jsx**: The unified action hub for users.
- **Messages/Messages.jsx**: The real-time chat interface with integrated order actions.
- **Orders/Orders.jsx**: Comprehensive order tracking for buyers and sellers.
- **Marketplace/Marketplace.jsx**: Product browsing and discovery.

## 🎨 Design System

We use **Vanilla CSS** with a curated color palette and modern typography to ensure a premium, lightweight, and extremely customizable user interface. No bulky CSS frameworks are used, allowing for maximum performance and design control.
